# Categorias (de Produto)

Base path: `/produtos/categorias`

---

## Cadastrar Categoria

`POST /produtos/categorias`

## Atualizar Categoria

`PUT /produtos/categorias/{id}`

## Excluir Categoria

`DELETE /produtos/categorias/{id}`

## Consultar Categoria

`GET /produtos/categorias/{id}`

## Listar Categorias

`GET /produtos/categorias`
