# Subcategorias (de Produto)

Base path: `/produtos/subcategorias`

---

## Cadastrar Subcategoria

`POST /produtos/subcategorias`

## Atualizar Subcategoria

`PUT /produtos/subcategorias/{id}`

## Excluir Subcategoria

`DELETE /produtos/subcategorias/{id}`

## Consultar Subcategoria

`GET /produtos/subcategorias/{id}`

## Listar Subcategorias

`GET /produtos/subcategorias`
